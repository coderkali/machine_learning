Hypothesis Testing Basics

Telling a real effect apart from a run of good luck.

2 notebooks

The problem behind this topic

A new checkout page converted at 12% against the old page's 10%. The team wanted to ship it.

But they had only tested 80 visitors. Flip a fair coin 80 times and you will often get 45 heads — the gap could easily be noise.

The question is not "is the new number bigger?" It is "is it bigger than luck can explain?"

Hypothesis testing assumes there is no real difference, then computes how often chance alone would produce a gap this large. If that is rare enough, the difference is worth believing.

🔑 The one idea

Assume nothing happened, then ask how surprising your result would be if that were true.

Hypothesis Testing (Z-Test) - Two Sample

H0 : mu_new = mu_old Ha : mu_new > mu_old (right-tailed test)

Z_test = [ (xbar_new - xbar_old) - (mu_new - mu_old) ] / (sigma / sqrt(n))

condition: n >= 30 (large sample, use Z-test not t-test)
