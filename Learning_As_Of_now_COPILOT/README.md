# Learning As Of Now — Copilot

This is a new, offline-friendly map of the topics represented in the `MACHINE_LEARNING` repository. Open `index.html` in a browser. No build step or server is required.

The map deliberately keeps evidence categories separate:

- **Learned evidence**: a notebook, app, or worked note exists.
- **In progress**: material exists but the repository records open gaps.
- **Archive evidence**: earlier study preserved under `Foundations_Archive/`.
- **Planned / scaffold**: a folder or roadmap branch exists without topic evidence yet.

The source paths in each topic drawer are relative to this folder, so the map can be used as a navigation page for the repository.
