# Repository Instructions

This repository has two separate ML workflows.

## ML Teaching

When the user asks to:

* teach a notebook
* explain today's learning
* help understand an ML concept
* study an `.ipynb`
* continue an ML lesson
* save learning notes into a notebook

read and follow:

`ML_TEACHER_PROMPT.md`

Do not automatically run the learning-website workflow.

## ML Learning Website

When the user explicitly asks to:

* update the ML learning website
* update the visual roadmap
* update the knowledge tree
* incorporate today's learning into the website

read and follow:

`CODEX_LEARNING_PROMPT.md`

These are separate workflows.

Do not modify either instruction file unless the user explicitly requests it.
