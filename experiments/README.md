# Experiments

This directory keeps temporary exploration away from the main curriculum.

Good examples include comparing embedding models, testing chunk sizes,
evaluating prompts, or measuring vector-search behavior. Each experiment should
have one question, a reproducible setup, a result, and a short conclusion.

When an experiment becomes useful and stable, promote it into a topic example
or a project. Remove or archive abandoned work instead of letting this folder
become a collection of unexplained files.
