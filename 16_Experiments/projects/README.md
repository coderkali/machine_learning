# Projects

This directory is for substantial applications that combine several learned
topics. Projects are added gradually; the instructor PDF does not provide a
named project list or project rubrics.

A project normally contains:

```text
project-name/
├── README.md
├── architecture.md
├── src/
├── tests/
└── diagrams/       # only when separate diagram files are useful
```

Its README should explain:

- the problem and goal;
- the architecture and technology choices;
- how data and requests flow through the system;
- how to run and verify it;
- what I learned;
- which curriculum modules it demonstrates.

Small single-topic exercises belong beside their topic in `AI_ML_Series/`, not
here.
