# Script moments guide — making every reel interesting (2026-10-06)

Approved by Kali on 2026-10-06. Inspired by a long ML-overview script he liked: it never used an equation,
yet every algorithm *felt* understood. This guide does **not** change our format. Keep: max 3 ideas, one
connected argument, real project data, desi-teacher phrases (`PHRASE_BANK.md`), concepts not code.
It adds **moments** — the lines people remember — and each one is written **with its animation**.

## The rule

**Every reel has at least 3 of the 6 moments below.** Write the line and its 🎬 animation together;
a moment without an animation is not done. Mark them in the script table (e.g. `M1`, `M3`) so they're easy to check.

## The 6 moments

### M1 · Make it talk
Give the algorithm / sensor / row a voice. It becomes a character.
- Reference: *"It literally says: you are most similar to these five people, so I classify you as male."*
- Ours: "Let's ask each sensor one question. Since when have you been watching Delhi's air?
  New Delhi says: since 2016. Pusa says: only sixty-six days, sir."
- 🎬 Each row lights up and answers in a speech bubble.

### M2 · Let the viewer compute first
Give a tiny problem with real numbers; pause; the viewer gets there half a second before the narrator.
- Reference: *"Three male, two female → majority vote → male."*
- Ours: "We need only five. How many do you think pass? … Fifty."
- 🎬 Counter ticks up, crosses the "5" line, keeps going.

### M3 · Push the knob to both extremes
Show what breaks when the setting is too small and too large; the right value becomes obvious.
- Reference: *"K too small copies one noisy point; K too large averages everything."*
- Ours: "Ten days and every station passes, even broken ones. Ten years and almost nothing passes.
  Two years sits in between."
- 🎬 Slider moves; table rows flip green/red live.

### M4 · One "wait, really?" fact
One surprising, true line per reel. Plan it on purpose.
- Reference: *"Only the support vectors matter — the rest of the data could disappear."*
- Ours: "All of Delhi becomes one pixel."
- 🎬 Everything else fades; the thing that matters stays exactly the same.

### M5 · Explain it against what they already know
Contrast with the previous idea, or with Java — our audience's home ground.
- Reference: *"KNN doesn't learn an equation like linear regression, nor draw a boundary like logistic."*
- Ours: "Punjabi Bagh is like a cache entry. Big, but it expired in 2018. You wouldn't serve that to a user."
- 🎬 Row gets a TTL-expired stamp.

### M6 · Picture first ("Imagine…")
Paint a mental picture in words, then let the animation deliver it.
- Reference: *"Imagine lifting the data into three dimensions…"*
- Ours: "Imagine one box, forty-five kilometres wide, dropped over Delhi. Connaught Place, Dwarka, Noida —
  all get the same number."
- 🎬 Map swallowed by one grey square.

## What NOT to copy from the reference
- "Next up, we have…" list transitions — each beat must answer the last.
- "I already made a video on this, check it out later."
- Many ideas per video — still max 3.
- Sensitive toy examples (gender, ethnicity) — use real project data or Java-world examples.

## Checklist before sending a script to Kali
- [ ] ≤ 3 ideas, each beat answers the last
- [ ] ≥ 3 moments (M1–M6), each tagged in the table
- [ ] every moment has a 🎬 line
- [ ] numbers are real (source cited at the top)
