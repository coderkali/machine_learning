Idempotent

A file already on disk is skipped. The second full run downloaded nothing and took under two seconds.

Missing is normal

A day the station did not report has no file. It is counted — 16 of them — and the run carries on. Any other HTTP error stops it.

Raw means raw

No filtering, no reshaping while downloading. Every fix happens downstream, so the original is always there to re-derive from.

One gap worth closing

Each file is written straight to its final name. If a run is interrupted mid-write, a half-written file is left behind — and the next run sees it exists and skips it for good. Not blocking, but it is the one way this collector's idempotency can quietly break.

DAF-05 — one row per day, with tomorrow attached

notebooks/05_daily_table.ipynb → data/interim/daily_17.csv. Bars use a log scale, so 467,816 and 487 fit in one picture.

The five columns

ColumnMeaningAt 18:00?
pm25_meanmean of the day's hoursnot yet
hourshours with a reading, 0–24—
pm25_until_17mean of hours 00:00–17:00yes
validhours ≥ 18 (D-002)—
targettomorrow's pm25_mean, only if tomorrow is validthe answer

pm25_until_17 is what a model may use; pm25_mean is what tomorrow's target is made of. Today's full mean does not exist yet at 18:00.

Checked, not assumed

The target was re-derived independently — by calendar date, not by row — and compared on all 571 rows.

15 min → hour → day

Hourly first, because D-002's rule counts hours. Averaging 15-minute readings straight into a day would weight an hour with four readings more than an hour with one.

By date, not by row

The table covers every calendar day before the target is built, so "next row" and "next day" are the same thing. A plain shift(-1) on a gappy table would pair Monday with Wednesday.

IST midnight

The +05:30 offset is kept from the raw text onwards. Parsed naively, every day boundary would land at 05:30 in the morning Delhi time.

Where the invalid days fall

83 days have fewer than 18 hours. Rose bars are winter months — the months that hold nearly every Poor day.

January 2026 loses 10 days and February 7, in the middle of the only winter. Each invalid day costs exactly one training row — the day before it loses its answer — which is why 488 valid days give 487 targets (the first day has no day before it). Still, 156 of the 487 targets are Poor or worse.
